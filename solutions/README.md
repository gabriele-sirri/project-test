# Solutions

**Not on the main branch until the deadline.** Keep this folder on the `solutions` branch and merge it after the labs.

- `lab1/` … `lab4/`: solution notebooks of the course exercises.
- `original-macros/<case>/`: the original C++ macros of the earlier editions, grouped by use-case (`examples/<case>`).
  `not-yet-documented-cases/` holds material (ARIADNE, moon shadow, unfolding) that has no use-case folder yet; `misc-exercises/` holds macros not matched to a case.

Notebook paths (`../../examples/...`) are valid from `solutions/labN/`.
